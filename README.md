# Lahore Housing Price Dashboard 🏠

This repository contains a **data visualization dashboard** analyzing housing prices in Lahore, Pakistan.  
It highlights property price variations across different locations and property types using interactive charts.

## 📊 Features
- **Minimum Price by Location**  
  Shows entry-level housing prices in areas like Wahdat Road, Bahria Town, Johar Town, and Pak Arab Housing.

- **Summary Metrics**  
  - Total property types: 20.51K  
  - Locations covered: 461  
  - Total property value: 2.05bn PKR  

- **Property Type Distribution**  
  Pie chart showing proportions of Houses, Upper Portions, Lower Portions, Flats, Rooms, Farm Houses, and Penthouses.

- **Average Price by Property Type**  
  Farm Houses and Homes dominate high averages, while Rooms represent the most affordable segment.

- **Maximum Price by Location**  
  Gulberg Lahore and Valencia Housing show premium property prices, while areas like Muslim Town and Allama Iqbal Town remain mid-range.

- **Maximum Price by Property Type**  
  Houses reach up to 3M PKR, while Flats, Portions, and Rooms remain comparatively lower.

## 🛠️ Tech Stack
- **Power BI / Tableau / Python (Matplotlib, Seaborn)** for visualization
- **Pandas / Excel / CSV** for data preprocessing
- Dataset: Lahore housing listings

  NOTE(** This data has been taken from Open Data Pakistan.**)
